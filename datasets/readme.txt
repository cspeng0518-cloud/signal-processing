C01 多类型电磁信号通用感知 —— 数据集说明
================================================

一、数据来源
  仅使用赛题官方提供的数据集（C01 赛题数据集 01/02/03），未引入任何外部数据、
  未使用任何预训练大模型权重（主干与前端均为本方案自研并从随机初始化训练）。

二、原始数据
  数据集 01/02/03 各包含一份 *_train_part_00x.parquet 与一份示例 IO 包
  （rf_signal_sample_io_v1.0）。训练数据即从中派生，无人工标注、无额外清洗标签。

三、预处理（离线一次性）
  1) 解析 iq 字段（[(I,Q), ...] 实数序列，原始长度 512 或 1024）
  2) 512 点样本右侧补零至 1024，保留有效长度掩码
  3) 按 task 分文件落盘为 float32 memmap：
       datasets/<task>/iq.memmap   形状 [N, 1024, 2]
       datasets/<task>/meta.json   含 split 索引、标签、样本顺序
  4) 按 80/10/10 分层切分 train/val/test（分层键为该样本的标签组合）

四、评测时数据
  评测服务挂载的测试 Parquet（task / sample_id / iq 三列）由 run.sh 读入，
  本包不包含任何测试数据，也不依赖本地缓存。

五、数据使用声明
  训练集仅用于模型参数学习；验证集用于早停与超参选择；测试集仅做最终一次评估。
  未针对官方榜单做任何数据回灌或伪标签。
